# README media

This directory contains media used by the repository's main README.

- `pathlab-demo.mov` is the supplied PATHLAB screen recording.
- `pathlab-demo-poster.png` is a still generated from that recording.
- `digit-warehouse-reference.png` is a still generated from supplied Agility
  Robotics footage. Its source is
  [Digit's Next Steps](https://www.agilityrobotics.com/content/digits-next-steps).
- `humanoid-planning-stack-reference.png` is an externally sourced planning
  architecture reference. Its source is the linked
  [YouTube video](https://www.youtube.com/watch?v=VeutCk1xYzI).

The two external reference images are included for attribution and research
context. They are not PATHLAB output, and no ownership or license beyond their
original sources is asserted here.
