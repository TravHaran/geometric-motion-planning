# README media

This directory contains media used by the repository's main README.

- `pathlab-demo.gif` is an optimized animation generated from the supplied
  trimmed PATHLAB screen recording.
- `digit-warehouse.gif` and `agility-path-planner-simulation.gif` are optimized
  animations generated from supplied Agility Robotics footage. Their source is
  [Digit's Next Steps](https://www.agilityrobotics.com/content/digits-next-steps).
- `humanoid-planning-stack-reference.png` is an externally sourced planning
  architecture reference. Its source is the linked
  [YouTube video](https://www.youtube.com/watch?v=VeutCk1xYzI).

The external reference media is included for attribution and research context.
It is not PATHLAB output, and no ownership or license beyond the original
sources is asserted here.
